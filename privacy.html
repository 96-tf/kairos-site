Privacy policy

Last updated: 25 September 2026

Who uses Kairos

Kairos is a personal, single-user application. It is used only by its owner and is not available to anyone else.

What data Kairos accesses

With the owner's permission, Kairos reads and writes events on the owner's own Google Calendar in order to check availability and schedule time blocks. It does not access any other Google data.

How the data is used and stored

  • Calendar data is processed only to provide scheduling for the owner.
  • It is handled on a private server controlled by the owner.
  • It is never sold, shared with third parties for their own use, or used for advertising.

Google API Services User Data Policy

Kairos's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions can be raised via GitHub.
